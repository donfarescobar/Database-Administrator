## 3. Roadmap Jenjang Rekomendasi (Referensi Industri)

Urutan umum yang relevan untuk peran Senior DBA di sektor perbankan Indonesia:

### Level Foundation
| Sertifikasi | Kenapa Relevan |
|---|---|
| ITIL v4 Foundation | Bahasa bersama untuk incident/change/problem management di enterprise |
| Oracle OCA / SQL Server MCSA-equivalent / PostgreSQL Associate | Membuktikan fundamental engine utama |
| RHCSA | Server Linux tempat database production biasanya berjalan |

### Level Intermediate
| Sertifikasi | Kenapa Relevan |
|---|---|
| Azure DP-300 atau AWS Database Specialty | Migrasi/hybrid cloud makin umum di bank Indonesia |
| ISO 27001 Lead Implementer/Auditor | Kepatuhan ISMS — nilai plus besar untuk audit readiness |
| COBIT Foundation | IT governance framework yang dipakai regulator |

### Level Senior/Specialist
| Sertifikasi | Kenapa Relevan |
|---|---|
| Oracle OCP + Data Guard/RAC specialization | Core banking masih dominan Oracle |
| CISSP | Security leadership — untuk jalur DBA → security architect |
| PMP / PRINCE2 | Untuk jalur manajerial (IT project manager) |

> 📌 Prioritas sebaiknya mengikuti **engine yang dipakai organisasi saat ini** — sertifikasi pada teknologi yang tidak pernah Anda tangani secara hands-on kurang bermakna.

## 4. Maintenance Sertifikasi

Beberapa sertifikasi punya syarat renewal:

| Sertifikasi | Siklus Renewal | Cara Renewal |
|---|---|---|
| Microsoft role-based (DP-300, dll.) | 1 tahun (free online renewal) | Assessment online di Microsoft Learn |
| AWS | 3 tahun | Re-exam atau continue education credits |
| Oracle | 2–3 tahun (tergantung track) | Upgrade exam atau course completion |
| CISSP | 3 tahun | CPE credits (120 poin) + annual maintenance fee |
| ITIL 4 | Tidak kadaluarsa (Foundation) | — |
| RHCSA | 3 tahun | Re-exam atau upgrade ke RHCE |

Set kalender reminder H-90 hari sebelum expiry untuk tiap sertifikasi aktif.
