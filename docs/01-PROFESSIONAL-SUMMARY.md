# Professional Summary
## Senior Database Engineer / Administrator — Banking & Enterprise

---

## 1. Ringkasan Eksekutif

Profesional database dengan fokus pada **reliability, security, dan performance** sistem database skala enterprise, khususnya di sektor **perbankan dan jasa keuangan** yang menuntut *zero-tolerance downtime*, *audit-ready compliance*, dan *data integrity* tingkat tinggi.

Berpengalaman menangani siklus penuh pengelolaan database — mulai dari **perancangan arsitektur**, **implementasi & migrasi**, **tuning performa**, **high availability/disaster recovery**, hingga **hardening security** dan **kepatuhan regulasi**.

---

## 2. Area Kompetensi Utama

### a. Database Engineering
- Perancangan skema database (logical & physical data modeling) untuk sistem OLTP dan OLAP
- Normalisasi/denormalisasi strategis untuk performa vs integritas data
- Partitioning, indexing strategy, dan capacity planning
- Migrasi database lintas platform (on-prem ↔ cloud, engine ↔ engine)

### b. Database Administration
- Instalasi, konfigurasi, patching, dan upgrade database engine (Oracle, MS SQL Server, PostgreSQL, MySQL/MariaDB, DB2)
- User & privilege management (least privilege, role-based access control/RBAC)
- Backup & recovery strategy (full, incremental, log shipping, PITR — Point-in-Time Recovery)
- High Availability: clustering, replication (synchronous/asynchronous), failover automation

### c. Security & Compliance (Banking-grade)
- Data encryption at-rest & in-transit (TDE, TLS 1.2+/1.3)
- Data masking & tokenization untuk data sensitif (PII, PAN/kartu, rekening nasabah)
- Audit trail & logging sesuai kebutuhan regulator (OJK/BI) dan internal audit
- Segregation of Duties (SoD) antara development, operation, dan audit

### d. Performance & Reliability Engineering
- Query tuning & execution plan analysis
- Root cause analysis (RCA) untuk incident performa/downtime
- Capacity planning berbasis tren pertumbuhan data transaksi
- Load testing koordinasi dengan tim aplikasi sebelum go-live

### e. Automation & Tooling
- Scripting otomasi (PowerShell, Python, Bash, T-SQL/PL-SQL) untuk operasional rutin
- Infrastructure as Code (Terraform/Ansible) untuk provisioning database environment
- CI/CD untuk database change (schema migration terkontrol — Flyway/Liquibase)
- Monitoring & alerting terintegrasi (Zabbix, Prometheus+Grafana, native vendor tools)

### f. Data Governance & Reporting
- Kolaborasi dengan tim bisnis untuk kebutuhan pelaporan (regulatory report, MIS report)
- Integrasi ETL/ELT antara sistem transaksional dan data warehouse
- Dokumentasi data dictionary dan data lineage

---

## 3. Filosofi Kerja

1. **"Boring is good"** — sistem database yang baik adalah yang tidak menimbulkan kejutan; stabilitas dan prediktabilitas lebih penting daripada fitur baru yang belum teruji.
2. **Automate everything repeatable** — pekerjaan manual berulang adalah sumber human error; otomasi adalah bentuk *risk mitigation*.
3. **Security by design, bukan by afterthought** — kontrol akses dan enkripsi dirancang sejak awal, bukan ditambahkan setelah insiden.
4. **Documentation is part of the deliverable** — perubahan tanpa dokumentasi dianggap tidak selesai.
5. **Assume failure, design for recovery** — setiap komponen dianggap bisa gagal; fokus pada *Mean Time to Recovery (MTTR)*, bukan hanya *uptime*.
